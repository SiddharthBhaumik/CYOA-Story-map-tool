Keep these in mind

The building blocks

Sections

Story stages processed in order. A node can only produce events in the next section.

Events

Facts, choices, or outcomes that can be on or off. Creating an event alone does not make it happen.

Nodes

Named rule groups. Each formula lists the conditions it needs and the event it gives.

Formulas

Every required event must be active. For example, Key + Lantern means both are needed.

Isolated choices

Optional middle-stage events switched directly by the player rather than produced by a node.

Results

Exhaustive analysis checks combinations and reports reachable endings, routes, conflicts, and dead ends.
