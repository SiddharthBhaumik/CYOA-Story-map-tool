A quick-start guide for interactive fiction

Story Node Map is a browser-based planning tool for choose-your-own-adventure (CYOA) stories. Define events, connect them with logical rules, and explore how different choices lead to different endings—all before you write every branch.

Open Story Node Map → Read the tutorial ↓

No installation required. Open the tool in your browser and start experimenting.

How the tool thinks

Instead of drawing every possible branch manually, you describe what can happen and the rules that connect events.

1

Define events

Create story facts or choices, such as “You took the key” or “The guard trusts you.” Events represent things that may be true in a playthrough.

2

Build rule-based nodes

Use nodes and formulas to specify which combinations of earlier events produce an event in the next section.

3

Analyze the outcomes

Explore switch combinations and inspect endings, routes, conflicts, formulas that never fire, and paths that lead nowhere.

Your first story map

Start small. You can add more sections and rules after you understand the flow.

  1. Open the tool. Use the Open Story Node Map button above. The planner opens in a separate page within the same site.
  2. Choose a starting point. Use Load sample story to inspect an example, or choose Start empty to create your own design.
  3. Add sections. Think of sections as stages in the story. The first section contains starting events; the final section contains ending events.
  4. Add events. Give each event a clear, distinct name. Prefer specific statements such as “Has brass key” over vague labels such as “Key”.
  5. Create nodes and formulas. A node evaluates the events in its section and can produce an event in the next section. A formula describes the conditions needed for that output.
  6. Try different choices. Open the play board and toggle starting events or isolated choices to see how the story state changes.
  7. Review the results. Check which endings are reachable and whether any combinations cause conflicts or dead ends.
  8. Save your work. The tool auto-saves in your browser. Use the save/load area to copy or load the story as JSON text so you can keep a backup or move it elsewhere.

Four concepts to know

These are the building blocks of the planner.

Sections

Stages in the story. Events in one section can influence what becomes true in the next.

Events

Facts, decisions, or story conditions that can be on or off in a given scenario.

Nodes and formulas

A node produces an output event when a formula's required events are all on. More specific formulas can take priority over formulas that require fewer events.

Endings and routes

The results view helps you inspect which endings are reachable and which choices or rules lead there.

Tip: test one rule at a time.

When a result surprises you, simplify the story temporarily. Check the input events, verify the formula conditions, and then add complexity back in. If equally specific rules compete, inspect the conflict report.

Save, share, and continue later

  • Your current work is stored in the browser's local storage, so it is associated with that browser and device.
  • For a portable backup, open the save/load section and copy the story JSON text somewhere safe.
  • To restore a backup, paste the saved JSON into the load area and use the load control.
  • Keep a separate backup before making major changes to a complicated story.

Note: browser-local auto-save is not the same as cloud storage. Clearing browser data or switching devices may remove access to a locally saved story, so export a backup when it matters.
